# 基于 RAG 的 Java 程序课程辅导系统 —— 毕业设计总体规划

> 版本：v1.0（2026-11-11）
> 周期：12 周（3 个月内答辩）
> 仓库：https://github.com/taurusru1/java-course-rag

---

## 一、课题定位

**题目**：基于 RAG 的 Java 程序课程辅导系统设计与实现

**一句话定位**：面向高校 Java 程序设计课程，构建"课程资料 + 代码示例 + 题库 + 编译报错"四类知识资产统一检索的辅导系统，让学生用自然语言提问即可获得**带出处的讲解、可运行的代码、可定位的报错修复建议和可追溯的错题复盘**。

**与普通文档问答的区别（论文创新点来源）**：

| 编号 | 增量能力 | 普通文档 RAG | 本系统 |
|---|---|---|---|
| C1 | 代码感知切分与检索 | 按段落切，代码被切碎 | 代码块整体保留、方法级切分、代码与讲解绑定 |
| C2 | 编译报错诊断 | 只能答"什么是异常" | `javac` 报错归一化 → 错误模式库检索 → 定位知识点 + 修复建议 |
| C3 | 题库判分与错题溯源 | 无 | 答题 → 自动判分 → 错题关联知识点 → 反推应复习的课程片段 |
| C4 | 可复现的评测体系 | 无 | 检索/生成/诊断三维指标 + 基线对比 + 消融实验 |

> 注意：混合检索（dense+sparse）、HyDE、RRF、Reranker 是底座自带能力，**不作为创新点**，只在论文"相关工作/系统实现"中说明选型理由。

## 二、系统架构（三端）

```
┌─────────────────────────────────────────────────────────────┐
│  frontend  Vue 3 + Vite（学生端 / 教师端）                     │
│  问答 · 课程导航 · 题库练习 · 错题本 · 报错诊断 · 文档导入       │
└───────────────────────────┬─────────────────────────────────┘
                            │ HTTP / SSE
┌───────────────────────────▼─────────────────────────────────┐
│  backend  Spring Boot 3.3.13 + Java 17 + JPA + MySQL         │
│  用户与权限 · 课程/章节/题目 CRUD · 判分 · 错题记录 · 会话历史   │
│  通过 AiModuleClient 调用 Python AI 服务                        │
└───────────────────────────┬─────────────────────────────────┘
                            │ HTTP / SSE
┌───────────────────────────▼─────────────────────────────────┐
│  ai-service  Python 3.11 + FastAPI + LangGraph               │
│  解析(MinerU/pypdf) → 章节感知切分 → BGE-M3(dense+sparse)     │
│  → Milvus → HyDE/RRF/Reranker → LLM 生成 → 结构化引用          │
│  特色：代码感知切分、报错诊断、评测脚本                          │
└─────────────────────────────────────────────────────────────┘
```

**为什么是三端**：业务（用户、判分、错题）用 Java 实现贴合课题名称，答辩时可直接展示 Spring Boot 代码；AI 能力用 Python 生态（LangGraph、BGE-M3、Milvus SDK）实现成本最低；两端通过 HTTP/SSE 解耦，符合工程实践，也便于分章节写论文。

## 五、论文结构（与工程一一对应）

1. 绪论：背景、意义、国内外研究现状（RAG、教育问答、代码智能）、研究内容
2. 相关技术：RAG、向量检索、BGE-M3、Milvus、LangGraph、Spring Boot、Vue
3. 需求分析：角色（学生/教师）、功能需求、非功能需求、用例图
4. 系统设计：总体架构、知识库设计（四类资产 + 元数据 schema）、检索与生成流程、数据库设计、接口设计
5. 系统实现：数据管道、代码感知切分、报错诊断、判分与错题溯源、前后端实现
6. 系统测试与实验：功能测试、评测方案、基线对比、消融实验、结果分析
7. 总结与展望
