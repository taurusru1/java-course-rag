# 后端接口说明（v0.2）

> 服务：`javacourse-backend`（Spring Boot 3.3.13 / Java 17 / MySQL 8）
> 本地启动：`docker compose -f docker-compose.dev.yml up -d` 后 `java -jar target/javacourse-backend-0.0.1-SNAPSHOT.jar`
> 默认端口 8080；本地联调示例使用 18082。除登录与健康检查外，均需请求头 `Authorization: Bearer <token>`。

## 1. 认证

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/auth/login` | 入参 `{"account":"student","password":"123456","role":"STUDENT"}`，返回 `token` 与用户信息 |
| GET | `/api/auth/me` | 当前登录用户 |
| POST | `/api/auth/logout` | 注销当前 token |

演示账号：`student/123456`（学生）、`teacher/123456`（教师），首次启动由 `DataSeeder` 创建。

## 2. 课程与章节

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/courses` | 课程列表 |
| POST | `/api/courses` | 新建课程（`name` 必填） |
| GET | `/api/courses/{id}` | 课程详情 |
| PUT | `/api/courses/{id}` | 更新课程 |
| DELETE | `/api/courses/{id}` | 删除课程 |
| GET | `/api/courses/{id}/chapters` | 章节列表（按 chapterNo 升序） |

## 3. 练习与错题

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/practice/questions?courseId=&chapterId=` | 题目列表（不含答案） |
| GET | `/api/practice/questions/{id}` | 题目详情（不含答案） |
| POST | `/api/practice/questions` | 新建题目（`courseId`、`stem` 必填） |
| POST | `/api/practice/submit` | 交卷判分，入参 `{"questionId":1,"answer":"B"}` |
| GET | `/api/practice/wrong` | 错题列表：错题 → 题目（含答案与解析）→ 知识点 |
| GET | `/api/practice/stats` | 学习统计：`total`、`wrong`、`accuracy` |

判分规则：
- `CHOICE` / `JUDGE`：忽略大小写比较；
- `MULTI`：提取字母后排序比较，忽略顺序与分隔符；
- `FILL`：去空白、转小写后比较；
- `CODE`：当前按文本归一化比较，后续接入 javac/java 沙箱运行判题。

## 4. 报错诊断

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/diagnose` | 入参 `{"error":"...javac 报错原文..."}`，返回命中案例、置信度与修复建议 |
| GET | `/api/diagnose/cases` | 案例库列表 |
| GET | `/api/diagnose/cases/grouped` | 按类别（编译错误 / 运行时异常）分组 |
| POST | `/api/diagnose/cases` | 新增案例（`errorCode` 唯一） |

匹配策略：`javac_pattern` 正则命中记 0.9；`error_code` 关键词全部出现记 0.7；低于 0.5 视为未命中，前端可降级到课程问答检索。每次诊断写入 `diagnostic_records`，用于统计诊断准确率。

## 5. 智能问答（RAG）

前端 → Spring Boot → Python AI 服务的三段式链路。Spring Boot 只做会话编排与鉴权，检索与生成在 Python 侧。

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/chat` | 入参 `{"query":"...","courseId":1}`，返回 `sessionId` 与 `taskId` |
| GET | `/api/chat/{sessionId}` | 轮询结果，返回 `status`、`answer`、`sources` |
| GET | `/api/chat/{sessionId}/stream` | SSE 流式输出（`text/event-stream`） |
| GET | `/api/chat/sessions` | AI 侧会话列表 |
| GET | `/api/chat/sessions/{sessionId}/messages` | 某会话历史消息 |
| DELETE | `/api/chat/sessions/{sessionId}` | 删除会话 |

Python 侧对应接口：`/ai/query/start`、`/ai/query/{taskId}/status`、`/ai/query/{taskId}/stream`、`/ai/query/sessions*`。
`ai.service.base-url` 默认 `http://127.0.0.1:9000`，可用环境变量 `AI_SERVICE_BASE_URL` 覆盖。

引用结构：`{"source":"knowledge_base","chunk_id":"","course_name":"","chapter_name":"","chapter_path":"","source_file":"","page_number":0}`。

## 9. 资料管理与导入

### 9.1 Spring Boot 侧

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/documents` | `multipart/form-data`，字段 `file` / `courseId` / `docType`，返回 `documentId`、`taskId` |
| GET | `/api/documents?courseId=` | 资料列表（含 `status`、`courseName`） |
| GET | `/api/documents/{id}` | 单个资料及其导入任务状态 |
| DELETE | `/api/documents/{id}` | 删除资料记录 |

`status` 取值：`processing` / `completed` / `failed`。

### 9.2 Python 离线服务侧

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/ai/import/start` | 入参 `{"fileUrl": "D:\\...\\ch04-io.md"}`，仅接受绝对路径；同步解析入库 |
| GET | `/ai/import/{taskId}/status` | 返回 `status`、`chunks`、`message` |

`status` 取值：`completed` / `duplicate`（文件哈希已存在）/ `failed`。

导入实现：`EducationDocumentParser` 解析 → `CodeAwareSplitter` 切分（代码块原子保留）→
`HashingHybridEmbedder` 生成 128 维向量 → 追加进 `OfflineEngine.records`。
上传文件落在 `data/corpus/java/uploads/`，服务重启后 `build_index` 会一并加载。
