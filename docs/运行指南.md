# 运行指南（本地三端联调）

系统由四个进程组成：MySQL、Spring Boot 后端、Python AI 服务、Vue 前端。按下面顺序启动即可。

## 0. 环境要求

| 组件 | 版本 | 说明 |
|---|---|---|
| JDK | 17 | `JAVA_HOME` 指向 JDK 17 |
| Maven | 3.9+ | 或使用 IDEA 内置 Maven |
| Node.js | 18+ | 前端构建 |
| Python | 3.11 | 建议 `.venv` 隔离 |
| Docker | 任意 | 只用于跑 MySQL 8 |

## 1. 数据库（Docker MySQL 8，端口 3307）

```powershell
docker compose -f docker-compose.dev.yml up -d
docker exec javacourse-mysql mysql -uroot -pjavacourse -e "show tables" javacourse_kb
```

容器首次启动会自动执行 `db/schema.sql` 建 12 张表。若表缺失，可手动执行：

```powershell
docker exec -i javacourse-mysql mysql -uroot -pjavacourse javacourse_kb < db/schema.sql
```

## 2. 后端（Spring Boot，示例端口 18082）

```powershell
cd backend
mvn -DskipTests package
java -jar target/javacourse-backend-0.0.1-SNAPSHOT.jar --server.port=18082
```

启动成功的标志是日志出现 `Started KnowledgeBaseApplication`，随后：

```powershell
curl http://127.0.0.1:18082/health     # {"ok":true}
```

首次启动会自动创建演示账号：`student/123456`（学生）、`teacher/123456`（教师）。

## 3. Python AI 服务（端口 9000）

首次使用需安装依赖（项目自带 `.venv` 时可跳过）：

```powershell
uv venv .venv --python 3.11
uv pip install --python .venv\Scripts\python.exe -r requirements.txt
```

**离线降级模式**（无 LLM Key、无 Milvus 时可用，检索走本地哈希向量 + 词面混合打分，回答由片段抽取生成）：

```powershell
.venv\Scripts\python.exe -m uvicorn web.offline_service:app --host 127.0.0.1 --port 9000
curl http://127.0.0.1:9000/health      # {"status":"ok","mode":"offline","chunks":16,...}
```

语料目录默认 `data/corpus/java`，可用环境变量 `OFFLINE_CORPUS_DIR` 指向其他目录。

**完整模式**（需要 Milvus、BGE-M3、LLM Key）：按 `web/api` 下的服务与 `.env` 配置启动，接口契约与离线模式一致，Spring Boot 端无需改动。

## 4. 前端（Vue 3 + Vite，端口 5173）

```powershell
cd frontend
npm install
$env:VITE_API_TARGET = "http://127.0.0.1:18082"
npm run dev
```

浏览器打开 `http://127.0.0.1:5173`，用 `student/123456` 登录。页面：智能问答、课程与章节、练习与错题、报错诊断。

## 6. 常见问题

- **8080 被占用**：本机 8080 常被其他服务占用，用 `--server.port=18082` 启动，并让前端 `VITE_API_TARGET` 指向同一端口。
- **`Schema-validation: missing column [course_id]`**：`documents` 表缺少外键列，执行 `ALTER TABLE documents ADD COLUMN course_id BIGINT, ADD CONSTRAINT fk_documents_course FOREIGN KEY (course_id) REFERENCES courses(id);` 后重启。
- **`MinIO 未配置`**：不配置 `MINIO_ACCESS_KEY` / `MINIO_SECRET_KEY` 时文件上传不可用，其余功能正常。
- **Java 编译报 `非法字符: '\ufeff'`**：源文件被写入了 UTF-8 BOM，用无 BOM 编码保存即可（PowerShell 的 `Set-Content -Encoding UTF8` 会加 BOM）。
- **PowerShell 输出中文乱码**：`Invoke-RestMethod` 按 Latin-1 解码 JSON，属于终端显示问题，浏览器与数据库中的中文均正常。

## 7. 教师端：上传讲义直接进知识库

这条链路**不依赖 MinIO、也不依赖 Milvus**：后端把文件写到 `data/corpus/java/uploads/`，
再由 Python 离线服务解析、切分、向量化并加入内存索引，重启后也会被重新加载。

1. 用 `teacher / 123456` 登录，左侧导航出现「资料管理」。
2. 选择课程与资料类型，选一个 `.md` / `.docx` / `.pdf`，点「上传并入库」。
3. 列表状态变为「已入库」；`curl http://127.0.0.1:9000/health` 的 `chunks` 会增加。
4. 回到「智能问答」提问刚上传内容里的知识点，引用的 `source_file` 就是该文件。

链路：`POST /api/documents` → 落盘 → `POST /ai/import/start` → `OfflineEngine.import_file()`
（解析 → `CodeAwareSplitter` → 哈希向量 → 追加索引）。同一份文件重复上传会按文件哈希去重，
返回 `duplicate` 而不是重复入索引。
